把网页发到互联网上（在线版）—— 任何有网的地方都能看
==========================================================

这个文件夹就是「上传用」的成品：网页 + 视频 + 照片 + 音乐，全都是真实文件。
整个文件夹拖到下面任意一个平台，就会得到一个公网网址（https://…），
手机只要有 WiFi 或流量就能打开，不需要和电脑在同一个局域网。

【最快：Netlify Drop（不用装软件，2 分钟）】
  1. 电脑浏览器打开  https://app.netlify.com/drop
  2. 把本文件夹（妈妈生日快乐网站-在线版）整个拖进网页
  3. 等几秒，出现 https://xxxxx.netlify.app 这样的网址 —— 手机打开就能看
  4. 想长期保留 / 改个好记的名字：用邮箱注册免费账号即可

【备选：Cloudflare Pages】
  1. 打开 https://dash.cloudflare.com  ->  Workers & Pages  ->  Create  ->  Pages
  2. 选 Upload assets，把本文件夹拖进去，Deploy
  3. 得到 https://xxxx.pages.dev

【备选：Vercel】
  1. 打开 https://vercel.com  ->  Add New  ->  Project  ->  拖入本文件夹
  2. 得到 https://xxxx.vercel.app

【备选：GitHub Pages（免费稳定，国内有时慢）】
  1. 注册 github.com，新建一个仓库
  2. 把这些文件上传上去（网页上就能拖）
  3. 仓库 Settings -> Pages -> Source 选 main / root -> Save
  4. 得到 https://用户名.github.io/仓库名/

【国内访问更快、但要实名账号】
  · 阿里云 OSS / 腾讯云 COS：开通「静态网站托管」，把文件传上去，默认域名就能访问
  · 又拍云 / 七牛云：同样有免费额度的静态托管
  · Gitee Pages：需要实名认证

【注意事项】
  1. 网址等于钥匙：链接发给谁，谁就能看到全部内容。已加 robots.txt + noindex，
     搜索引擎不会收录，但请不要发到公开群里。
  2. 在线版是「只读」的：管理员面板照样能用，但你的修改只存在你自己这台设备的浏览器里。
     要更新线上内容：在电脑上打开网页 -> 管理员 -> 改完点「保存到网站文件夹」
     -> 再把这个文件夹重新上传一次（平台里选 Redeploy / 覆盖上传）。
  3. 音乐：公开网页上放商业唱片属于公开传播别人的录音制品，所以本在线版
     默认<b>没有</b>带 music 文件夹里的歌曲（music\ 是空的，页面不会报错，只是没声音）。
     想带上音乐有两个办法，风险由你自己判断：
       · 把 music 文件夹里的 mp3 拖进本在线版的 music\ 里，再上传；或
       · 双击上一层的「生成在线版（含音乐）.bat」，它会带音乐重新生成一次。
  4. 流量：三段视频合计约 4.6 MB，手机流量看一次就这么多；照片另算。
  5. 想换回本地版：本地那个文件夹里的 index.html 一直都能用，和在线版互不影响。

【音乐自查（很重要）】
  上传后先用浏览器打开这个地址：
      https://你的网址/music/zhendeaini.mp3
  · 能播放/能下载 = 音乐文件已经传上去了，打开首页点「进入」就有歌；
  · 显示 404 = 音乐文件夹没传上去，重新把整个文件夹上传一次。
  注意：浏览器会缓存网页（10 分钟），更新后请按 Ctrl+F5 强制刷新，手机上清一下缓存或换个浏览器。
  · 在线版里音乐文件名固定叫 zhendeaini.mp3（不管原文件叫什么，
    生成在线版时会自动改名并写进 photos\album.js），避免中文名在服务器上出问题。
